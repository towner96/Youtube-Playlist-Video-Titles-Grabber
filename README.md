# Youtube-Playlist-Video-Titles-Grabber
Use this when Youtube decides to remove videos from your playlist all of sudden and you want to identify the removed ones.

Instructions:\
1: Use extractNames.js in browser console (inspect) to grab all playlist's video titles visible on the tab.\
2: Copy them and paste them in any list comparison tools e.g., https://comparetwolists.com/ \
3: Click "Show unavailable videos" in the settings menu in three dots menu.\
4: Repeat 1st and 2nd step.\
5: Finally you can compare and find the ones eliminated by youtube.
